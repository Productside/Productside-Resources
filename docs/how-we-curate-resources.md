# How We Curate Resources

This repository is intentionally curated.

## What gets included

- public Productside learning resources
- public Productside framework pages
- public tools, templates, and educational materials
- public company and about pages that help visitors orient quickly

## What does not get included

- private or customer-specific materials
- raw exports or duplicated marketing-page content
- links that require insider context to understand
- anything that creates licensing, privacy, or confidentiality problems

## Update approach

- add resources when they are clearly useful and public
- remove or update stale links when site structure changes
- prefer human-reviewed curation over blind scraping

## Future automation

Private tooling may use link inventories or scraping helpers to propose updates, but public changes should still be reviewed by a human before merge.
